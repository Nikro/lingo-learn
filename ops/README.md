# Ops Notes

This folder stores durable project decisions and operating notes that should survive beyond a single agent session.

Use `ops/decisions/` for Architecture Decision Records (ADRs): small Markdown files that explain **what was decided**, **why**, and **what changes next**.

Do not store scratch output, downloaded references, prompt dumps, generated bulk content, localStorage exports, or temporary analysis here. Use `/tmp` or the ignored `workspace/` folder for that.
